MAIS QUE ACERTAR UMA LETRA

Cada sinal é um passo
para se aproximar.

O Quiz Libras é um espaço para exercitar o reconhecimento das letras do alfabeto manual. Observe os sinais, teste o que você sabe e descubra algo novo a cada tentativa.

Uma prática complementar para quem está começando. Libras é uma língua completa: o alfabeto é apenas uma parte dessa jornada.
