01 / O PROJETO

Aprender, praticar e explorar.

O Quiz Libras é uma proposta educacional que combina uma interface interativa com um modelo de inteligência artificial. O trabalho explora como o reconhecimento de padrões em imagens pode ser aplicado a atividades envolvendo o alfabeto manual.

A aplicação integra uma página web a um servidor Python. Nesse servidor, o modelo treinado pode analisar uma imagem e indicar a classe prevista, permitindo apresentar o resultado ao usuário.

O reconhecimento de letras em imagens é um recorte do projeto. A Libras possui estrutura linguística própria, expressões faciais e movimentos; o quiz não representa um tradutor completo da língua.

02 / PROPÓSITO

Objetivos do trabalho

Explorar a integração entre visão computacional e uma aplicação web voltada à prática do alfabeto manual.

Apoiar a prática

Oferecer atividades visuais que ajudem o usuário a associar representações de mãos às letras abordadas.

Aplicar inteligência artificial

Utilizar um modelo de classificação para reconhecer padrões nas imagens das classes treinadas.

Integrar as tecnologias

Conectar a interface do navegador ao processamento realizado pelo backend em Python.

Compreender as limitações

Observar como as condições das imagens influenciam os acertos e os erros do reconhecimento.

03 / EXPERIÊNCIA

Da imagem ao resultado

O fluxo conceitual de reconhecimento envolve cinco etapas:

  1. Entrada da imagemA aplicação recebe a imagem a ser analisada na atividade.
  2. Preparação dos dadosA imagem deve receber o mesmo tratamento utilizado no treinamento, incluindo tamanho e escala dos valores.
  3. Análise pelo modeloA rede neural calcula uma saída para as classes que aprendeu a distinguir.
  4. Identificação da classeA previsão é associada ao nome da classe, respeitando a ordem dos rótulos do treinamento.
  5. Exibição na interfaceO resultado retorna à aplicação web para apresentação ao usuário.
04 / RECONHECIMENTO

O papel da inteligência artificial

Um classificador de imagens aprende padrões a partir de exemplos rotulados. Durante o treinamento, seus parâmetros são ajustados para relacionar as características visuais das imagens às classes correspondentes.

Depois dessa etapa, o modelo salvo em modelo_libras.keras pode ser carregado para realizar novas previsões. O arquivo classes.npy mantém os rótulos necessários para transformar a saída numérica em uma classe compreensível.

Treinamento

Etapa de aprendizagem com exemplos. É realizada antes do uso do modelo na aplicação.

Inferência

Etapa de previsão sobre uma imagem. Utiliza os parâmetros já aprendidos pelo modelo.

Uma previsão pode estar incorreta. Mesmo uma pontuação alta do modelo não garante que a imagem tenha sido reconhecida corretamente.

07 / ANÁLISE CRÍTICA

Limitações e possibilidades

O desempenho depende da relação entre as imagens usadas no treinamento e aquelas analisadas durante o uso. Variações de iluminação, fundo, enquadramento e posição das mãos podem provocar erros.

  • Classes conhecidas: o modelo reconhece apenas as categorias contempladas no treinamento.
  • Condições de captura: imagens muito diferentes dos exemplos de treinamento podem reduzir a qualidade das previsões.
  • Imagens estáticas: uma imagem isolada não descreve toda a informação de sinais que dependem de movimento.
  • Avaliação: conclusões sobre desempenho devem ser apoiadas por testes com imagens separadas do treinamento.

Como possibilidades de evolução, podem ser exploradas a ampliação e a diversificação das imagens, melhorias no pré-processamento e avaliações com novos usuários e condições de captura.

Esta documentação não apresenta valores de acurácia ou resultados quantitativos: essas informações devem ser incluídas a partir da avaliação efetivamente realizada no projeto.

08 / DÚVIDAS

Perguntas frequentes

O quiz ensina Libras por completo?

Não. A proposta é apoiar a prática de representações do alfabeto manual. O aprendizado de Libras envolve também vocabulário, gramática, expressões e interação com a comunidade surda.

O modelo aprende a cada imagem enviada?

A inferência utiliza um modelo já treinado. Enviar uma imagem para classificação, por si só, não modifica os parâmetros desse modelo.

Por que imagens parecidas podem ter resultados diferentes?

Mudanças no fundo, na iluminação, no ângulo ou no enquadramento alteram os dados de entrada. O modelo pode ser sensível a essas diferenças.

Como avaliar a qualidade do reconhecimento?

Com um conjunto de teste separado do treinamento. Acurácia, precisão, revocação, F1 e matriz de confusão ajudam a compreender tanto o desempenho geral quanto os erros entre classes.
